# 音效目录

把音效文件放在这里，支持以下格式（按优先级尝试）：

```text
sounds/meep.mp3
sounds/meep.wav
sounds/meep.ogg

sounds/guagua.mp3
sounds/guagua.wav
sounds/guagua.ogg

sounds/gugugu.mp3
sounds/gugugu.wav
sounds/gugugu.ogg
```

- `meep`：meep 音效
- `guagua`：夜鹭音效
- `gugugu`：斑鸠音效

在页面命令输入框里输入：

```bash
meep
guagua
gugugu
```

即可播放对应音效。文件还没放进去时，终端会提示找不到音效。
